Tổng Quan Dự Án:

STORE_BUILDPC là nền tảng thương mại điện tử chuyên biệt, cung cấp giải pháp giúp người dùng tự do thiết kế và lắp ráp PC cá nhân hóa với trải nghiệm mua sắm hiện đại, tiện lợi.
  - Trải nghiệm tối ưu: Giao diện trực quan, thân thiện, đáp ứng nhu cầu của mọi đối tượng từ người dùng phổ thông đến chuyên gia công nghệ.
  - Cấu hình thông minh: Lựa chọn linh kiện liền mạch, tích hợp hệ thống tự động kiểm tra tính tương thích và cập nhật giá theo thời gian thực.
  - Vận hành toàn diện: Tích hợp đồng bộ hệ thống quản lý đơn hàng, kho bãi và thanh toán, mang đến quy trình mua sắm trọn vẹn.


Công nghệ sử dụng:
1. Frontend
• SPA mượt mà
• ReactJS và Router điều hướng
• Axios gọi API
• Context API lưu giỏ hàng
• Leaflet chọn vị trí giao hàng
• Tailwind CSS làm giao diện gọn gàng
• WebSockets báo mới ngay lập tức

2. Backend
• Java 17 và Spring Boot 3.3
• Spring Data JPA quản lý bảng dữ liệu
• MySQL lưu thông tin hệ thống
• Spring Security và JWT xác thực người dùng
• Lombok tối giản mã nguồn
